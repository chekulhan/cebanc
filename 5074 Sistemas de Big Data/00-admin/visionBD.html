Especialista orientado al procesamiento ETL local, modelado analítico y la creación de capas semánticas visuales para resolver problemas de negocio.

  • 📉Estadística básica: Análisis predictivo elemental para estimar tendencias.
  • 🧠KPIs de negocio: Interpretación de objetivos basados en métricas analíticas.

Semestre 2
Big Data Aplicado (Módulo 5075) 🎯 Objetivo: Construir y operar sistemas de datos a gran escala
⚙️ Perfil Profesional: Data Engineer & Cloud Architect

Ingeniero especializado en el despliegue de infraestructuras de datos distribuidas, almacenamiento masivo y automatización de pipelines.

  • 🌐Distributed systems: Gestión avanzada de clústeres y escalabilidad horizontal.
  • ⚙️PySpark: Procesamiento analítico distribuido en memoria de alta velocidad.
  • 🔁Pipelines de datos: Construcción de arquitecturas estables de ingesta de datos.
  • 🧩Airflow / dbt: Orquestación automatizada de tareas y workflows de datos.
  • 💾Data lakes: Modelos de almacenamiento masivo distribuidos y Cloud.
  • 📡Monitorización: Control proactivo de la salud del sistema (logs y alertas).
  • ✔️Calidad de datos: Validación estricta mediante sumas de verificación.
🎓 Resultado: El alumno construye, optimiza y opera sistemas distribuidos de datos masivos.
