# Matemáticas Booleano

With NumPy arrays, use & and |, not Python's and and or.

```
numeros = np.array([1, 2, 3, 4, 5, 6])

filters = numeros > 4
print(filters)
numbers[numbers > 3]

result = numbers[(numbers > 2) & (numbers < 5)]
result

names = np.array(["Ana", "Luis", "Carlos", "Marta"])
```
