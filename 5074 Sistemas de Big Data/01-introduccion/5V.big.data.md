Antes de hacer esta demostración, teniamos que haber hecho los primeros pasos con numpy en 02-basics-Colab.


Contexto

Una empresa de videojuegos quiere analizar los datos de 10.000 partidas realizadas por sus usuarios.

# Volumen 📦

```
import numpy as np

puntuaciones = np.random.randint(0, 101, 10_000_000)

print(puntuaciones.size)
print(puntuaciones.nbytes)
```

# Velocidad ⚡

```
import time

for i in range(10):
    nuevas_partidas = np.random.randint(0, 101, 2)
    print(nuevas_partidas)
    time.sleep(1)
```

# Variedad 🧩

```
usuarios = np.array(["Ana", "Luis", "Marta", "Carlos"])
```

# Valor 💰

```
puntuaciones = np.array([
    45, 72, 18, 95, 63, 31, 88, 52, 76, 20,
    100, 67, 39, 84, 55
])

print("Media:", np.mean(puntuaciones))
print("Máxima:", np.max(puntuaciones))
print("Mínima:", np.min(puntuaciones))
print("Mediana:", np.median(puntuaciones))

expertos = puntuaciones[puntuaciones >= 90]

print("Jugadores expertos:", expertos)

```
